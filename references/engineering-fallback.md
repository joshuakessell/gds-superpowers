# Engineering fallback: standalone-degraded

Load only when relevant installed Superpowers support is unavailable. This checklist is not its full skill set, hooks, or runtime. Existing scope and host permissions still apply.

Inspect the approved plan, actual diff and baseline. For retained behavior, write a behavioral regression and observe the intended failure before implementing the smallest correction. A missing import alone is not evidence that the behavioral assertion failed. Keep existing work intact; an explicitly approved disposable spike is a bounded exception, not production completion.

Verify the targeted test, then the relevant full suite. Review specification compliance and code quality as distinct checks against actual files. Use a separate reviewer when available; label in-context self-review accurately. Reproduce defects before diagnosing and fixing their cause. Stop after the configured repair limit.

Record commands, results, limitations and evidence pointers. Apply the game-specific checks in engineering.md. Wait for required human feedback; do not convert automated success into a claim of enjoyment. No automatic deployment, merge or release.
