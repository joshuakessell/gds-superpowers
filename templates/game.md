# Game brief

Status: draft. Nothing below is approved until supported by a real user approval.

## Intent and boundaries
Player fantasy, primary and supporting types, audience, goals, non-goals.

## Core experience
Primary action, challenge, session start/end, what resets or persists, and the supporting types' exact contribution.

## Visual and input direction
Camera, dimensionality, mood, art treatment, readability, inputs, first target device. Separate user choices from proposed defaults.

## First playable test
One hypothesis, minimum content, and what the user will try.

## Small future outline
Core prototype -> complete slice -> bounded expansion -> release. Detail only the next slice.

## Technical and evidence pointers
Existing engine/code, approved tools and constraints, important source links, canonical specs when already present.

## Open or delegated decisions
Do not present unconfirmed assumptions as user decisions.
